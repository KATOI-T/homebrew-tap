# KATOI-T Homebrew tap

The official [Homebrew](https://brew.sh) tap for
[SATSUMAESTRO](https://github.com/KATOI-T/SATSUMAESTRO), an agentic coding CLI that also runs on
local LLMs.

```bash
brew install katoi-t/tap/satsumaestro
satsumaestro --version
```

Or tap once and use the short name:

```bash
brew tap katoi-t/tap
brew install satsumaestro
```

Upgrade with `brew upgrade satsumaestro` and remove with `brew uninstall satsumaestro`.
macOS and Linux are supported. See the
[SATSUMAESTRO README](https://github.com/KATOI-T/SATSUMAESTRO#readme) for setup and usage.

Problems with SATSUMAESTRO itself go to the
[SATSUMAESTRO issues](https://github.com/KATOI-T/SATSUMAESTRO/issues). Problems with installing it
through Homebrew can go there too.
